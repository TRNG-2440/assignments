# Kyle's Python Labs
These are some hands-on practice labs and exercises. Unlike the assignments Joseph has given, don't worry about completing and being graded. These are just for practice.

## [Function Refactor](./Function%20Refactor%20Lab.md)
Take this big ugly function and break it down into multiple functions. This is practicing DRY and separation of concerns, as well as function definition.

## [Graceful Failure](./Graceful%20Failure%20Lab.md)
This simple program will raise exceptions. Add exception handling so the program and run successfully without crashing.

## [Flow Control](./Flow%20Control%20Lab.md)
Guided coding through the different flow control techniques in python, ends with fizzbuzz code challenge.

## [Functions and Lambdas](./Functions%20and%20Lambdas%20Lab.md)
Guided coding through different ways to express behaviors, ending with an implementation challenge.

## [Iterators](./Iterators%20Lab.md)
We didn't get time to cover iterators, but this is the mechanism that underpins for loop behavior iterating through collections like lists. This lab walks you through iterators and iterables, and ends with an exercise where implement the iter methods.
