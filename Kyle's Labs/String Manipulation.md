# String Manipulation

## Objective
Practice string methods and manipulation by cleaning and transforming a messy string.

## Setup
Create a new file called `string_lab.py`.

## Instructions
1. Start with the following string:
   ```
   messy = "  🎉HeLLo,$$   WORld!!! 🐍123 &^thiS** IS #@a TeSt...💀  "
   ```
2. Clean the string so that it contains only lowercase letters (no spaces, numbers, or punctuation)
3. Reverse the cleaned string
4. Print the result

## Expected Output
```
tsetasidlrowolleh
```
